# GeomLib

> Библиотека вычислительной геометрии: выпуклая оболочка, триангуляция, пересечения и геометрические запросы, с визуализацией результата.

Набор алгоритмов планарной вычислительной геометрии, оформленный как переиспользуемая библиотека и сопровождаемый демонстрационным приложением и обширным тестовым покрытием.

## Возможности

- **Выпуклая оболочка** (convex hull) множества точек.
- **Триангуляция** многоугольников/множеств точек.
- **Пересечения** геометрических примитивов (`intersections`).
- **Геометрические запросы** (`queries`): принадлежность, отношения фигур и т.п.
- Утилиты над фигурами (`shape_utils`) и базовые примитивы (`geometry`).
- **Визуализация** результатов работы алгоритмов.

## Технологии и концепции C++

- Проектирование переиспользуемой header-ориентированной библиотеки с чётким разделением модулей.
- Геометрические примитивы и алгоритмы на современном C++.
- Обширный набор модульных тестов на каждый алгоритм (GoogleTest).
- Сборка через Conan + CPM, dev-контейнер VS Code.

## Структура

```
include/
  geometry.hpp       — базовые примитивы (точки, векторы, фигуры)
  shape_utils.hpp    — утилиты над фигурами
  convex_hull.hpp    — построение выпуклой оболочки
  triangulation.hpp  — триангуляция
  intersections.hpp  — пересечения примитивов
  queries.hpp        — геометрические запросы
  visualization.hpp  — визуализация
tests/               — отдельный набор тестов на каждый модуль
```

## Стек

`C++` · `Conan` · `CPM.cmake` · `CMake` · `GoogleTest`

## Сборка

```bash
mkdir build && cd build
conan install --settings=build_type=Debug --build=missing ..
conan build --settings=build_type=Debug ..
```

В VS Code достаточно `F5` (conan + сборка + `lldb`).

## Запуск

```bash
cd build
./GeometryApp
```

## Тесты

```bash
cd build
ctest --output-on-failure
```
